# 🩺 AI Doctor Recommendation & Appointment System

A modern web application that helps users find the right doctor based on their disease and book appointments online. The system provides an intuitive interface for patients and an admin dashboard for managing doctors, appointments, and users.

## 🚀 Live Demo

🔗 https://doctor-recommendation-app.vercel.app/

## 📌 Features

- 🔍 AI-powered doctor recommendation
- 👨‍⚕️ Disease-based doctor search
- 📅 Online appointment booking
- 🔐 User authentication
- 👤 Patient dashboard
- 🛠️ Admin dashboard
- 📱 Responsive design
- ⭐ Doctor ratings and reviews
- 🗄️ Supabase database integration

## ⚙️ Installation

```bash
git clone https://github.com/shawal106khan/DoctorRecommendationApp.git

cd DoctorRecommendationApp

npm install

npm run dev
```

## 🔑 Environment Variables

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

> **Do not commit your `.env` file to GitHub.**
